Recall of 0.436 is the weaker figure, and deliberately so. A missed frame is not a missed event — the system observes each scene many times per second. A false alarm, by contrast, wastes a reviewer's time and erodes trust in the system.

How a frame becomes an incident

Detection alone is not enough. A bottle in a bin is not littering.

1

Detect

YOLOv8 finds litter and people in the frame, with confidence scores.

2

Track

ByteTrack assigns a persistent ID to each object, so the system can ask whether it moved and how long it has been there.

3

Locate

The bottom-centre of each box — the ground contact point — is tested against the restricted zone polygon.

4

Decide

Five conditions must all hold before an incident is raised.

5

Evidence

A photo and a 60-second before/after clip are saved. Every other frame is discarded.

The event rule

All five conditions are required.

1Detection confidence above threshold
2Object lies inside an active restricted zone
3A person was tracked nearby recently
4The object has stopped moving
5It stays still past the confirmation delay
A bottle in a bin → no person nearby, no alert.
Someone carrying a bottle → it keeps moving, no alert.
A one-frame false detection → gone next frame, no alert.
Someone drops a bottle and walks away → alert raised.
