Pipeline

How a frame becomes an incident

Detection alone is not enough. A bottle in a bin is not littering.

1

Detect

YOLOv8 finds litter and people in the frame, each with a confidence score.

2

Track

ByteTrack gives every object a persistent ID, so the system can ask whether it moved and how long it has been there.

3

Locate

The bottom-centre of each box, the ground contact point, is tested against the restricted zone polygon.

4

Decide

Five conditions must all hold before an incident is raised.

5

Evidence

A photo and a 60-second before/after clip are saved. Every other frame is discarded. Nothing is recorded continuously.

The decision layer

The five-condition event rule

This rule is the project's own design, and the reason raw detections never flood the reviewer.

All five required
1Detection confidence above threshold
2Object lies inside an active restricted zone
3A person was tracked nearby recently
4The object has stopped moving
5It stays still past the confirmation delay
What that rejects
Bottle sitting in a bin, nobody nearNo alert
Someone carrying a bottle across the zoneNo alert
One-frame false detectionNo alert
Drops a bottle and walks awayAlert raised
The algorithm is not detect trash. It is detect the transition from carried to dropped, near a person, inside a monitored area.

Get started

Installing the app

The APK is unsigned, so Android will warn before installing.

STEP 1

Download

Tap the Download APK button on an Android device.

STEP 2

Allow the install

When prompted, enable Install unknown apps for your browser.

STEP 3

Pair a camera

Sign in, then pair the device with a camera token from the dashboard.

The app sends frames to an inference gateway that runs on our own laptop. It is only reachable while that machine is online, so please contact us to arrange a live demonstration.
