# YELO - Python dependencies for the inference gateway
#
# Install with:
#     pip install -r requirements.txt
#
# Note: torch is a large download (~2 GB). The first install takes several
# minutes. A GPU is NOT required - the gateway runs on CPU by default.
#
# Versions below are the ones this project was developed and tested against
# (Python 3.14.3, Windows 11). The lower bounds are the minimum we know works;
# the upper bounds guard against breaking major releases.
